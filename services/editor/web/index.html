EMBEDDED EDITOR

회로를 만들고,
코드로 움직여 보세요.

보드·빵판·부품·배선을 편집하고 2D와 3D로 확인합니다.

사진 분석 없이 독립 실행 · 기본 기능은 API 키 불필요
01

편집할 프로젝트 선택

첫 LED 예제의 가이드를 따라 시작하거나 저장해 둔 프로젝트를 불러오세요.

아두이노 따라 하기 예제

① 준비물 확인 → ② 그림을 보며 배선 → ③ 실행 확인. 완성된 회로와 코드가 함께 열립니다.

다른 보드의 설계 예제 보기

보드별 예제

Arduino UNO는 로컬 코드 실행을 지원합니다. 다른 보드는 전용 실행 환경이 필요할 수 있습니다.

02

회로·코드 편집

상단 ‘작업 화면’에서 코드를 함께 보고 부품과 배선을 수정하세요.

03

직접 조작하며 실행

‘시뮬레이션 → 실행’을 누른 뒤 ‘입력·출력 → 조작·동작 검사’에서 버튼·센서를 조작하세요.

04

프로젝트 저장

완성한 회로·코드·구조물을 프로젝트 파일(.vlx)로 저장하세요.

분석기는 별도 서비스입니다. 분석 결과도 같은 .vlx 프로젝트로 가져올 수 있습니다. 기존 브라우저 저장 내용은 보존합니다.
