# 핀·선 끝점 검토 — 2026-10-22

## 추가한 흐름

1. 실제 사진 프로젝트에서 **문자·선 끝점 후보 찾기**를 실행한다.
2. OCR(사진의 문자 읽기) 원문과 확대 이미지를 대조한다. 붙여 읽은 핀 라벨은 사람이 구분한다.
3. 부품과 단자 이름·확인 근거를 입력한 뒤 **사진에서 실제 핀 찍기**로 접점 위치를 별도로 지정한다. 이름은 INFERRED, 데이터시트 핀 번호는 UNKNOWN이다.
4. 선 조각을 선택해 경로와 두 끝점을 확인한다. 양 끝에 닿는 핀을 지정하고 근거를 기록하면 INFERRED 연결 후보가 생긴다.
5. 서로 다른 두 핀, 동일 사진, 지정 위치와 끝점의 근접성(짧은 이미지 변의 4% 이내)을 검사한다. 교차·분기·루프는 연결 생성에서 제외한다. 위치 일치는 도통 증거가 아니며 가림 여부는 사람이 확인해야 한다.
6. 연결의 근거인 핀 위치가 변경되면 해당 geometry 기반 연결은 UNKNOWN으로 되돌린다. 원래 근거와 수정 이력은 보존한다.

사진은 1–4배 확대할 수 있다. 검토한 선 조각은 분홍색, 다른 선 조각은 노란색, OCR 영역은 파란색이다. 복잡한 윤곽은 선택했을 때만 사각형으로 표시한다.

## 입력과 출력

- `backend/vision/segments.py`: OpenCV 색상 영역과 중심 경로로 눈에 보이는 선 조각 후보 생성. 전기적 연결 생성 없음.
- `backend/vision/inspection.py`: OCR 관측, 사용자 핀 지정, 검토한 선과 핀 연결 API.
- `frontend/pinreview.js`, `pinreview.css`: 확대·검토 UI.
- Graph `text_observations`: 원문, 영역, OCR 점수, 원본 근거.
- Graph `wire_candidates`: 경로, 두 끝점 또는 복잡한 윤곽, UNKNOWN 상태.
