# 사진 구조물에 회로 부품 장착

사진 구조물의 역할·라벨과 회로 부품의 용도, 연결 관계를 이용해 각 부품의 장착 대상을 정한다. 이는 기능 구현을 위한 새 설계 위치이며 원본 사진의 숨겨진 장착 위치를 복원했다고 주장하지 않는다.

## 동작

- 제어보드는 기판 또는 장착판, 센서는 센서부, 서보는 좌우·상부·발목에 대응하는 구동부에 배정한다. 전원은 케이스에, 수동 부품은 연결된 부품의 구조물에 배정한다.
- `properties.evPhotoMount`에 구조물 ID, 표면 기준점, 표면 방향, 상대 위치, 회전을 저장한다. 유효한 사용자 선택을 유지하고 삭제된 장착 대상은 다시 배정한다.
- 구조물의 현재 위치·크기·회전과 분해 이동값을 공통으로 사용한다. 구조물을 드래그하는 중에도 부품과 배선을 즉시 갱신한다. 부품 이동은 장착면 내에서 상대 위치를 조절한다.
- 부품 선택 카드의 **장착 구조물**을 펼치면 장착 대상과 X/Y/Z 상대 위치를 변경할 수 있다. 변경은 실행 취소와 프로젝트 저장·다시 열기를 지원한다. 제어보드 속성 변경도 자동 저장한다.
- 배선 양 끝은 이동한 실제 핀 좌표에 고정한다. 같은 구조물에 속하는 배선은 함께 이동하고, 서로 다른 구조물에 연결된 배선은 양 끝의 이동량에 맞춰 늘어난다.
- 시뮬레이션 장면 캡처에는 항상 조립 상태의 부품과 배선을 사용한다. 분해 화면에서 시작해도 늘어진 분해 배선이 동작 모델에 저장되지 않는다.
- 기존 평면 회로의 부품 좌표·전기적 연결·코드는 장착 위치 변경으로 수정하지 않는다. 사진 구조물이 없는 프로젝트에는 기존 동작을 적용한다.

## 검증

- 관련 8개 테스트 파일, 48개 테스트 통과: 자동 배정, 분해, 실시간 이동, 회전·크기 변경, 같은 구조물의 배선 이동, 실행 취소, 보드 장착 대상 변경, 저장·다시 열기, 시뮬레이션 캡처, 기존 프로젝트 호환.
- 로봇 예제: 사진 구조물 16개, 장착 회로 부품 9개, 배선 21개. 조립·분해 상태의 핀 끝점 84개를 비교했고 좌표 오차는 0이다. 원래 배선과 코드는 유지됐다.
- 결과: `outputs/photo-mount/verification.json`, `vitest.log`, `typescript-comparison.json`, `patch-verification.json`, `vite-build.log`.
- `actual-views.png`는 실제 사진 구조물 지오메트리와 핀 좌표를 사용한 오프라인 배치 점검 그림이다. 회로 부품 몸체는 단순화했으며 브라우저 화면 캡처가 아니다.

자동 배정은 기구물 간섭, 케이블 길이·굽힘 반경, 고정 나사, 제조 치수의 검증을 포함하지 않는다. 브라우저 자동화 연결 오류(`timeoutMs`)로 실제 화면 조작 검증은 완료하지 못했다.
