# 편집기 도구 모음 축소

2026-11-17. 회로 화면을 넓히기 위해 큰 상단 카드를 한 줄의 작은 기능 그룹으로 변경했습니다. 편집·컴파일·시뮬레이션의 실행 경로는 유지합니다.

| 위치 | 항상 보이는 기능 | 펼쳐서 사용하는 기능 |
| --- | --- | --- |
| 상단 프로젝트 | 시스템 전환, 프로젝트 도구 | 파일 관련 메뉴 |
| 상단 시뮬레이션 | 실행, 정지 | 상태(컴파일·오류 설명), 입력·출력(센서·버튼·동작 검사·보드 출력) |
| 상단 작업 화면 | 회로 보기, 코드 함께 보기 | — |
| 상단 프로젝트 저장 | 프로젝트 저장 | 정보·저장 안내 |
| 회로 도구 | 부품 추가, 2D/3D, 가이드, 핀 연결 | 시점(맞춤·잠금), 편집(회전·복사·붙여넣기·되돌리기), 구조·오브젝트, 추가 도구 |
| 코드 도구 | 파일 목록, 실행 로그, 코드 도구 | 코드 전용 메뉴 |

데스크톱 도구 버튼은 32px 높이로 줄였습니다. 프로젝트 이름은 한 줄로 표시하고 긴 이름은 마우스를 올려 전체 내용을 확인합니다. 1100px 이하에서는 제목·저장과 도구 줄을 구분하며, 공간이 부족한 도구 줄은 가로로 이동할 수 있습니다. 작은 화면의 버튼은 38px 높이입니다.

상세 메뉴는 화면 위에 뜨며 메뉴를 열어도 회로 캔버스의 높이를 줄이지 않습니다. 화면 가장자리에서 메뉴 위치를 보정하고 바깥 클릭이나 Escape 키로 닫습니다. 선택한 부품의 이동·편집과 조립 가이드 기능은 유지합니다.

## 검증 범위

메뉴 위치·닫기·기존 동작 호출, 조립 가이드, 버튼·LCD 가상 MCU 실행을 자동 검사합니다. 빌드와 전체 관리 패치 재현도 확인합니다. 이번 작업 중 브라우저 제어 호스트에 연결할 수 없어 실제 브라우저의 시각 검사와 창 크기별 측정은 수행하지 못했습니다.

구현은 `services/editor/patches/velxio-compact-toolbars.patch`에 보관하며 설치 스크립트에서 순서대로 적용합니다.

최종 결과: Python 14개·편집기 16개·홈/튜토리얼 JS 3개 검사 통과. 관리 패치 36개 재적용 후 설치 소스 246개 일치. 실행 중인 8768 서버에서 새 JS/CSS와 학습 예제 5개가 제공되는 것도 HTTP로 확인했습니다.
