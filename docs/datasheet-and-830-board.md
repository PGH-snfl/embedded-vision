# 부품 데이터시트와 830구 빵판

사진·영상 분석 후 **② 부품 확인 → 부품 데이터시트 보기**에서 부품 종류, 모델 후보, 표시된 마킹, 확인이 필요한 전압·값·핀 정보를 확인한다. 확인된 카탈로그나 일치하는 모델 후보에 원문 링크가 있으면 함께 보여 준다. 일치하는 원문이 없으면 검색 링크를 제공한다. HTML 요약을 저장할 수 있다. 제조사 데이터시트를 생성하거나 사진에서 확인할 수 없는 사양을 확정하는 기능은 아니다.

새로 여는 자동 구성 시뮬레이터는 830구 빵판(63열, 전원 레일 4개)을 사용한다. 기존 저장 프로젝트는 보존되며 새 레이아웃은 별도 편집 초안으로 열 수 있다. 2D와 3D의 행 표시는 실제 핀 좌표에 맞췄다. 시뮬레이터의 각 전원 레일은 연속 연결로 모델링한다. 실물에서 중간에 끊어진 레일이 있는지는 별도 확인해야 한다.

UNO, LED, 저항, 버튼, 빵판과 점퍼선은 입체 부품과 재질을 개선했다. 모양은 시뮬레이션용 표현이며 정확한 제조 치수나 실물 제작 검증을 뜻하지 않는다. 다른 종류의 부품은 기존 일반 3D 표현을 사용한다. LED 밝기와 연결 계산은 기존 2D 시뮬레이터와 공유한다.

테스트 기록과 캡처: `outputs/datasheet-realistic/verification.json`. 실제 브라우저에서 새 빵판의 UNO 밝기 예제는 약 20.2ms 주기의 PWM 갱신을 보였다. 전체 TypeScript 검사는 기존 외부 소스 진단으로 통과하지 않지만 이전 기록과 비교해 새 진단은 없었다. HTML 내용 생성은 테스트했으며 자동 브라우저 다운로드 완료는 확인하지 못했다.
