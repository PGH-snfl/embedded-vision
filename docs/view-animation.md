# 보기 전환 애니메이션

- 조립 보기·분해 보기·회로 배선의 모든 방향 전환에 720ms 애니메이션을 적용한다. 부드러운 시작·끝 속도를 사용하고 위치·회전·크기를 보간한다.
- 구조물과 해당 구조물에 장착된 부품은 같은 진행률로 이동한다. 숨기는 부품은 작아지며 사라지고, 표시하는 부품은 장착 위치에서 나타난다.
- 배선은 중간 경로를 변형하고 투명도를 조절한다. 양 끝은 매 프레임 표시 중인 실제 핀에 고정한다. 회전 보간 중에도 핀에서 떨어지지 않는다. 기존 경로의 꺾임도 유지한다.
- 전환 도중 다시 보기를 바꾸면 현재 표시 위치·회전·크기·배선 경로에서 다음 전환을 시작한다. 같은 보기 버튼을 반복해서 누르면 재시작하지 않는다.
- 카메라는 목적지 배치의 실제 모델 크기를 계산해 위치·중심·확대율을 부드럽게 변경한다. 수직 2D 전환과 반대편 보기도 카메라를 이동한다. 2D→3D 버튼은 기존 요구대로 현재 시점을 유지하며 회전 제한만 해제한다.
- 마우스로 화면을 조작하면 카메라 자동 이동이 즉시 중단된다. 관성 이동은 활성화하지 않는다. OS의 ‘동작 줄이기’ 설정에서는 전환을 즉시 적용한다.
- 애니메이션은 뷰어의 임시 상태이며 저장된 부품 좌표·배선·코드는 변경하지 않는다. 다른 프로젝트의 전환 상태는 적용하지 않는다. 시뮬레이션 캡처는 기존의 조립 상태 좌표를 사용한다.

## 확인 결과

- 자동 테스트: 장착 부품의 동반 이동, 6가지 보기 전환 중 배선 끝점, 전환 중 재선택, 반복 클릭, 동작 줄이기, 기존 회로 호환, 카메라 종료·중단 및 기존 편집 기능을 확인한다. 실행 기록은 `outputs/view-animation/vitest.log`.
- 실제 로봇 예제: 구조물 16개·회로 부품 9개·배선 21개. 6개 전환의 78개 중간 프레임에서 배선 끝점 3,276개를 비교했고 좌표 오차는 0이다. 원본 데이터는 변경되지 않았다.
- CPU에서 경로와 배선 지오메트리를 계산한 중앙값은 프레임당 약 4.4ms, 95백분위는 약 8.3ms다. 브라우저 렌더링·GPU 성능 수치는 아니다. 결과는 `outputs/view-animation/actual-verification.json`.
- TypeScript 전체 기존 오류 359개에 추가 오류는 없다. 빌드·패치 재현 검증 결과도 같은 출력 폴더에 기록한다.
- 실제 브라우저 조작 확인은 CUA 연결 오류(`timeoutMs`)로 완료하지 못했다.
