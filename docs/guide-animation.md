# 한 단계 배선 안내와 가이드 애니메이션

2026-11-17. 배선의 양 끝을 나누어 지시하지 않고 한 문장·한 단계로 안내합니다.

> ① 제어 보드 U1 5 핀 → ② 빵판 A23 구멍을 점퍼선 하나로 연결하세요.

①·②는 두 단계가 아니라 연결 위치 번호입니다. 점퍼선 하나는 안내 한 단계이며, 부품을 빵판에 꽂을 때도 여러 다리를 한 단계에서 함께 안내합니다. 안내 데이터의 단계 수·원래 배선·코드를 변경하지 않습니다.

- 단계가 바뀌면 설명이 부드럽게 나타나고, 그림에서 선이 ①에서 ②로 이어집니다.
- 3D 화면에서도 저장된 배선 경로를 따라 연결 방향을 한 번 보여줍니다. 이는 **조립 안내**입니다. 전류·전압 또는 MCU 실행 결과를 나타내지 않습니다.
- 핀 강조와 연결 위치 확대도 부드럽게 전환합니다. 마우스로 화면 조작을 시작하면 카메라 이동을 즉시 중단합니다.
- **↻ 다시 보기**로 현재 단계의 안내를 다시 재생합니다. 다음 단계로 넘어가거나 배선을 변경하면 이전 안내는 남지 않습니다.
- 삭제·이동 등으로 현재 배선이 원래 안내와 달라지면 문장·그림·애니메이션을 숨기고 변경 안내를 표시합니다. 새 연결을 임의로 만들어 표시하지 않습니다.
- 운영체제/브라우저의 **동작 줄이기** 설정을 따르면 움직임을 끄고 정지 그림으로 확인할 수 있습니다.

## 구현

`services/editor/patches/velxio-guide-animation.patch`에 단일 문장, SVG 연결 그림, 3D 배선 경로 재생과 관련 검사를 보관합니다. 설치 스크립트에서 기존 패치 뒤에 적용합니다.

브라우저 제어 호스트에 연결할 수 없어 이번 변경의 실제 화면 시각 검증은 수행하지 못했습니다. 자동 검사·빌드·HTTP 제공 확인과 구분합니다.

검증 결과: 안내 문장·한 단계 유지·경로 보존·동작 줄이기·카메라 전환 관련 검사 30개 통과. 관리 패치 37개 재적용 후 소스 250개 일치. 실행 중인 서버에서 새 애니메이션 JS와 기존 예제 5개 제공을 확인했습니다.
