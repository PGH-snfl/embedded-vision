# 사진 한 장에서 가려진 배선 추정

2026-10-22: 입력 하나라는 요구에 맞춰 기본 화면을 추가 시점 대조에서 단일 사진 추정으로 변경했다. 이전 다각도 데이터/API는 호환용으로 남겼지만 추가 사진 업로드를 기본 흐름에서 제거했다.

## 동작

1. `가려진 배선 추정 · 사진 1장`의 버튼을 누른다. 새 사진의 VLM 부품 분석이 완료될 때도 현재 사진에 이 추정을 실행한다.
2. HSV 색상 분리 → 가는 중심선 추출 → 교차점에서 선 조각 분리 → 같은 색상의 두 조각을 비교한다.
3. 양끝의 방향이 서로를 향하는지, 굵기가 비슷한지, 간격이 과도하지 않은지 검사한다. 기존 보드·LCD 영역과 많이 겹치는 후보는 표면/인쇄선일 수 있어 순위를 낮춘다.
4. 최대 30개 가설을 순위순으로 표시한다. 같은 끝점을 공유하는 가설은 대안으로 표시한다. 상위 30개 밖의 대안도 있을 수 있다.
5. 청록 실선은 검출한 조각, 주황 점선은 미관측 구간을 잇는 가설이다. 점선은 실제 전선의 숨은 모양을 재현한 것이 아니다.
6. 기존에 위치를 지정한 실제 핀이 두 바깥 끝점에 하나씩 대응되면 선택한 가설을 INFERRED 연결로 회로 초안에 반영할 수 있다. 이름/핀 번호를 임의 생성하지 않는다. 핀이 없어도 경로 가설은 표시된다.

## 점수와 범위

- 학습된 배선 복원 모델이 아닌 OpenCV 기반 색상·형상 규칙이다. VLM은 기존 부품 인식에 사용된다.
- `ranking_score`는 순위용 점수이며 신뢰 확률/정확도가 아니다. 경로 가설 상태는 INFERRED이며 실제 전기적 연결은 별도 검증 대상이다.
- 빨강·주황·노랑·초록·파랑 범위를 지원한다. 검정/흰색, 반사, 보드 인쇄, 긴 완전 가림, 선 묶음, 같은 색상의 교차는 제한된다.
- 짧은 한 가림 구간을 잇는 후보를 만든다. 여러 가림을 관통한 전체 케이블 추적이나 부품의 알려진 표준 배선을 정답으로 채우는 기능은 아니다.
- 촬영 내용에 정답 연결 정보가 없으므로 단일 사진만으로 실제 연결 정확도를 보장하지 않는다. 가장 높은 점수도 오인식일 수 있다.
- 선택한 연결은 INFERRED이며 확정 net, 조립용 검증, KiCad 검사 통과로 취급하지 않는다. 핀 위치 변경 시 UNKNOWN으로 돌아간다.

## 데이터/API

- `POST /api/projects/{project}/occlusion/infer`: `expected_revision`, `asset_id`.
- `Graph.wire_hypotheses[]`: 원본 사진, 관측한 두 경로, 추정 gap, 색상, 순위 점수, 이유, 근거 ID, 선택한 연결 ID.
- `POST /api/projects/{project}/occlusion/hypotheses/{id}/adopt`: 검증된 현재 버전과 기존 핀 위치로 후보를 INFERRED 연결로 채택한다.
- 같은 입력 재분석은 후보를 중복 저장하지 않는다. 기존 연결/선택한 가설과 충돌하면 채택을 차단한다. 가설의 순위는 생성 시점의 부품 영역을 사용한 스냅샷이다.

## 검증 결과

- 신규 16개 포함 전체 145개 테스트 통과. 기존 KiCad 검사는 메모리 확보를 위해 VLM을 잠시 중지하고 수행, 이후 복구했다.
- 단절된 합성 전선의 gap 검출, 연속 선/서로 다른 색상/빈 사진의 불필요한 가설 차단, 경쟁 후보 보존, 방향·거리·굵기 필터, 교차점 분리, 핀 없는 연결 채택 차단, 수정 충돌, 핀 이동 시 재검토를 검사했다.
- 실제 Arduino/LCD 사진 한 장으로 30개 경로 가설을 생성해 웹에서 표시했다. 실제 핀 이름·배선 net은 자동 생성하지 않았다. 정답 회로와 비교한 정확도 평가는 수행하지 않았다.
