# 3D 단계별 조립 가이드

사진 분석 뒤 지원하는 새 회로를 시뮬레이터로 열고 **3D 편집 → 단계별 조립 가이드**를 선택합니다. 이전·다음 버튼으로 부품 삽입과 점퍼선 연결을 확인합니다. 부품 하나의 모든 다리와 연결 구멍을 한 단계에서 표시하고 점퍼선은 양쪽 끝을 한 단계에 표시합니다. 확대 그림과 3D에서 같은 번호와 색으로 핀과 빵판 구멍을 대응합니다. 삽화의 부품 모양은 단순화한 것이므로 실제 핀 위치는 3D 표시와 부품 표기를 함께 확인합니다. 안내 순서는 부품을 먼저 꽂고 선을 연결하도록 정렬합니다.

3D 편집기에서 점퍼는 시작점 ①과 도착점 ②를 표시하고 부품은 각 다리와 구멍을 번호별로 표시합니다. 얇은 반투명 대각선이 연결 위치를 가리킵니다. 단계를 이동하면 연결 위치가 화면에 들어오도록 카메라를 맞춥니다. 카메라를 직접 움직인 후에는 **3D 연결 위치 확대**로 다시 해당 위치를 볼 수 있습니다. 가이드를 닫으면 위치 표식도 사라집니다.

이 안내는 사진에 원래 있던 배선을 복구한 결과가 아니라 생성된 새 설계의 조립 위치입니다. 프로젝트에 assembly 단계 정보가 있는 경우에만 표시됩니다. 실제 기기를 조립하기 전 전원을 끄고 부품 종류·극성·핀 배열 및 빵판의 전원 레일 연결 상태를 확인해야 합니다. 이 화면은 실제 조립이나 안전성을 검사하지 않습니다.

사용자가 회로를 편집하여 해당 단계 또는 같은 부품의 다른 다리 연결이 없어지거나 3D 핀 위치를 찾을 수 없으면 해당 그림이나 강조를 숨기고 경고합니다. 가이드는 편집 내용으로 자동 재작성되지 않으며 최초 생성 설계의 단계를 유지합니다. 회로를 크게 변경했다면 현재 설계에 맞춰 직접 확인하거나 최초 제안을 복원하세요. 사진 분석에서 생성한 지원 회로를 시뮬레이터로 열 때 제공하며, 일반 파일 가져오기로 연 모든 프로젝트에 자동 생성되는 기능은 아닙니다.
