# 자동 급수 참조 회로 · v2

SEN0193 → Arduino UNO A0 → 코드 → D5 → 330Ω → IRLZ44N 게이트 → 12V 펌프.

이 설계는 사용자 장치의 복원이 아닌 새 참조 회로다. 실제 장치를 제작하거나 시험한 결과는 아니다. 회로도는 [SVG](../frontend/watering-circuit.svg), 업로드용 코드는 [watering_control.ino](../outputs/pump-driver/watering_control.ino), 편집 가능한 프로젝트는 [watering.vlx](../outputs/pump-driver/watering.vlx)다.

## 부품과 연결

| 부품 | 선정 및 연결 |
|---|---|
| U1 | Arduino UNO R3, USB 5V 공급 |
| S1 | DFRobot SEN0193: 빨강 VCC→5V, 검정 GND→GND, 파랑 SIG→A0. 제조사 연결 그림 기준이며 제품 단자 표기도 확인 |
| RG1 | 330Ω, D5와 Q1 G 사이. 예제 선정값 |
| RPD1 | 100kΩ, Q1 G와 S 사이. 초기화 시 꺼짐 유지. 예제 선정값 |
| Q1 | IRLZ44N TO-220AB: 1=G, 2=D, 3=S, 금속 탭=D. D→펌프 −, S→12V − |
| M1 | Adafruit #1150: +→별도 12V +, −→Q1 D |
| D2 | 1N5822: A→펌프 −, 띠가 있는 C→펌프 + |
| PS1 | 별도 정전압 12V 전원. 1A 이상을 후보로 두되 실제 기동·정지 전류와 보호 조건을 확인한 뒤 확정 |
| C1 | 470µF/25V 전해: +→12V +, −→12V −. 예제 선정값 |
| C2 | 100nF/25V 이상 세라믹: 펌프 양 단자 가까이. 예제 선정값 |
| R1/D1 | D5→1kΩ→녹색 LED A, LED C→GND. 선택적 상태 표시 |

UNO GND와 12V −를 공통으로 연결한다. 12V +와 UNO 5V는 연결하지 않는다. 펌프 전류가 흐르는 M1–Q1–PS1 경로는 단자대·납땜 보드로 구성하고, 빵판은 게이트와 상태 신호에 사용한다. 펌프 회전 방향에 맞춰 물통 흡입관과 화분 배출관을 연결한다.

## 확인한 사실 · CONFIRMED

- SEN0193: 공급 3.3–5.5V, 출력 0–3V. [DFRobot 제조사 자료](https://wiki.dfrobot.com/sen0193/)
- 센서 포트 배치는 제조사 연결 그림에서 프로브를 아래로 돌려 본 방향이다. 외형·치수·단자 간격은 간략 모형이며 실제 제작용 도면이 아니다. 연결 그림은 `outputs/pump-driver/sources/SEN0193-connection.png`로 보관했다.
- #1150: 정격 12V, 동작 전류 200–300mA, 최대 유량 100mL/min. 이 동작 전류는 기동·정지 전류의 보장이 아니다. [Adafruit 제품 자료](https://www.adafruit.com/product/1150)
- IRLZ44N: G/D/S 핀 배열과 5V 게이트 구동 조건의 온 저항을 데이터시트에서 확인했다. 임계 전압만으로 완전 도통을 판단하지 않는다. [Infineon 데이터시트](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irlz44n-datasheet-en.pdf)
- 1N5822: 3A/40V 계열, 색 띠는 캐소드. 실제 전류·온도 조건은 데이터시트 적용이 필요하다. [Vishay 데이터시트](https://www.vishay.com/docs/88526/1n5820.pdf)

## 설계·시뮬레이션 가정 · INFERRED

센서 건조/젖음 ADC 560/280, 급수 시작/정지 500/360은 보정 전 예제값이다. UNO 기본 5V ADC에서 3V는 약 614이므로, 이전 예제의 시작값 650을 사용하지 않는다. 실물에서는 펌프 전원을 끄고 흙의 건조·충분한 젖음 값을 읽은 뒤 기준과 방향을 조정한다.

유량 1.5mL/s와 토양 흡수율·용량은 동작 설명용이다. 모터는 48Ω·5mH의 R/L 등가 부하로 표현하고, MOSFET과 다이오드는 근사 SPICE 모델을 사용한다. 실물 기동 전류·회전 속도·열·유량 정확도를 보증하지 않는다.

코드는 건조 시 켜고 젖으면 끄는 두 기준으로 잦은 켜짐/꺼짐을 줄인다. 연속 15초 구동 또는 ADC 상한 625 초과 시 출력을 끄고 Reset 전까지 잠근다. 이 로직은 센서의 모든 단선·고장·빈 물통을 감지하지 못한다. 물통 수위 센서는 이 회로에 포함되지 않는다.

## 남은 실물 확인 · UNKNOWN

사용자의 실제 펌프·전원 모델, 기동/정지 전류, MOSFET 발열, 전원 보호 조건, 배선·커넥터 정격, 토양 보정과 실측 유량은 미확인이다. 전원 정격과 조립을 확인한 뒤 전류 제한 전원으로 짧게 시험해야 한다.

## 실행 검증

ngspice에서 게이트 HIGH의 펌프 전압·전류, LOW·전원 OFF의 정지, 코일 전류 차단 시 다이오드 클램프를 검증한다. 실행 모형은 LED와 관계없이 펌프 전압·전류를 읽고, 끊어진 게이트·전원·공통 접지·센서 경로에서는 멈춘다. AVR에서 실제 컴파일 코드를 실행해 습도 피드백과 15초 제한을 확인한다. 증거 파일은 `outputs/pump-driver/`에 보관한다.
