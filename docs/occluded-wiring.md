# 가려진 배선의 추가 시점 검토

2026-10-22 구현. 자동으로 숨은 배선을 복원하는 모델이 아니라, 다른 각도에서 드러난 경로를 기존 핀과 대조해 기록하는 기능이다.

## 사용 순서

1. 원본 사진의 **핀·선 끝점 검토**에서 두 핀의 이름과 실제 접점 위치를 저장한다. 가려진 이름은 추측해서 입력하지 않는다.
2. **가려진 배선 해결 · 다른 각도 대조**를 연다.
3. 배선을 바꾸지 않은 같은 장치를 옆·반대 방향에서 촬영하여 **다른 각도 사진 추가**로 올린다. 영상에서 이미 추출한 프레임도 선택할 수 있다.
4. 원본 시작·도착 핀을 선택한다. 원본 접점이 확대되어 표시된다.
5. 추가 사진에서 시작 접점 → 보이는 경로의 중간 지점 → 도착 접점 순서로 클릭한다. 잘못 찍으면 마지막 점을 취소한다.
6. 같은 장치인지와 양끝의 핀 대응을 확인하고 근거를 입력한다. 전체 경로가 끊김 없이 보이는 경우에만 해당 항목에 체크한다.
7. 저장 후 검토 이력에서 연결 근거를 연다. 해당 사진과 회로의 연결 후보가 강조된다.

## 결과와 제한

- 전체 경로 보임: `INFERRED`, 사용자 대조에 따른 추론 연결. 보정된 신뢰도 숫자를 만들지 않는다.
- 가림 남음: `UNKNOWN`, 연결값 null, 사진 위의 연결 경로는 빈 배열. 보이지 않는 구간을 이어 그리지 않는다.
- 자동 `CONFIRMED` 없음. 색상, OCR, VLM 출력만으로 전기적 연결을 확정하지 않는다.
- 동일 이미지 해시의 복제, 같은 핀 두 번 선택, 원본 핀 위치 누락, 같은 위치의 양끝, 이미 알려진 연결 덮어쓰기, 오래된 수정 버전은 차단한다.
- 다른 각도에 동일 부품이 있는지는 사용자가 대조한다. 자동 부품 추적·3D 복원·도통 측정은 구현 범위가 아니다.
- 이미지 해시 비교는 동일 파일 내용의 복제를 걸러낼 뿐, 잘라내기·재인코딩한 사진이나 실제로 배선을 바꾼 장치를 자동 판별하지 못한다.
- 원본 핀 위치가 바뀌면 관련 연결은 다시 `UNKNOWN`이 된다. 기존 검토와 근거는 남는다.
- 새로운 근거로 기존 UNKNOWN 연결을 갱신할 수 있다. 이미 INFERRED/CONFIRMED인 연결은 기존 검토 화면에서 먼저 검토해야 한다.
- 계속 가려진 배선은 추가 촬영이나 분리한 전선의 도통 측정이 필요하다. 회로에 연결된 상태의 낮은 저항값만으로 특정 전선의 연결을 증명할 수 없다.

## 데이터와 API

`POST /api/projects/{project}/occlusion/resolve`

필수: `expected_revision`, `asset_id`, `from_terminal`, `to_terminal`, `points`(2~200), `same_system_checked`, `endpoints_checked`, `entire_wire_visible`, `note`.

`Graph.wire_reviews[]`에 추가 사진, 기존 두 핀 ID, 표시한 점, 전체 경로 관측 여부, 근거 ID, 연결 ID를 저장한다. 기존 단자의 원본 사진 좌표는 유지한다. 과거 검토와 Evidence는 수정·삭제할 수 없다. 기존 0.1.0 그래프는 빈 검토 목록으로 호환된다.

## 검증

- 신규 18개 포함 전체 **129개 테스트 통과**. 기존 KiCad/시뮬레이션 회귀 검사 포함. KiCad 검사 중 메모리 확보를 위해 로컬 VLM을 잠시 중지하고 검사 후 복구했다.
- 독립 합성 테스트 저장소에서 브라우저 클릭 → UNKNOWN 저장 → 추가 전체 경로 검토 → 같은 연결의 INFERRED 갱신을 확인했다. 검토 2건, 연결 1건, 확정 연결 0건.
- 실제 Arduino/LCD 사진 프로젝트는 r3, 핀 0개, 연결 0개로 유지된다. 실제 추가 시점이 없으므로 숨은 배선의 정답이나 실사 복원 정확도는 검증하지 못했다.
