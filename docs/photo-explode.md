# 사진 구조 조립·분해 보기

사진 분석의 `objects`는 각 판·프레임·외장·다리·발판·기판·구동 모듈을 독립 ID와 조립 기준 위치로 저장한다. `details`는 같은 모듈의 작은 부속이나 표면 장식에만 사용한다. 이 분리 기준은 기존 단일 `photo_system` 호출의 지시에 포함된다. 분해 보기를 위해 AI를 추가 호출하지 않는다.

편집기 상단의 **조립 보기 / 분해 보기 / 회로·배선**으로 전환한다.

- 조립 보기: 사진의 독립 구조물을 원래 상대 위치에 모아 보여준다.
- 분해 보기: 판과 프레임 등을 서로 벌린다. 점선으로 조립 위치를 표시하고, 가운데에 실제 네이티브 회로 부품과 배선을 함께 표시한다. 내부 부품 선택으로 정보 카드를 확인할 수 있다.
- 회로·배선: 외형 모형을 숨겨 회로를 넓게 편집한다. 분해 상태에서 회로 부품의 이동이나 배선 편집을 활성화하면 이 보기로 전환한다. 구조물 이동은 화면 변환의 역변환을 적용해 원래 저장 좌표에 반영한다.

`photoAssemblyLayout.ts`가 표시 위치와 역변환을 계산한다. 사진 구조를 회로의 표시 영역에 맞춰 비례 확대하고, 회로 전체에는 동일한 높이 이동을 적용한다. 따라서 부품 핀과 전선의 상대 연결은 유지된다. 조립/분해 전환 자체는 네이티브 부품 좌표, 회로 연결, 코드, 초안 및 편집 이력에 쓰지 않는다.

기존 생성기가 추가한 큰 설명용 상자는 사진 분해 보기에 중복 표시하지 않는다. 대신 사진에서 분리한 실제 외형 근사와 기능 실행용 회로를 함께 보여준다. 표시 배치는 내부 구조를 설명하기 위한 것으로 실측 장착 치수나 기구 간섭 검증 결과가 아니다.

운동 미리보기로 넘기는 회로 그래픽에도 같은 조립 기준을 적용한다. 사진 모형의 표시 확대 비율을 역변환하여, 어느 보기에서 실행하더라도 동일한 부품·케이블 위치를 전달한다. 분해 위치를 실제 조립 위치로 저장하지 않는다.

기존 사진 분석 결과에도 독립 `objects`가 있으면 바로 적용되며 재분석은 필요 없다. 이미 통짜로 생성된 하나의 외장에 대해 내부 패널을 자동 복원하는 기능은 아니다. 앞으로 입력하는 사진은 패널별 분리 기준으로 분석한다.
