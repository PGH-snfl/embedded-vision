# 회로와 연동하는 주변 오브젝트

급수 시제품을 열면 회로 옆에 화분·물통·펌프·호스를 함께 표시한다. v2는 SEN0193·MOSFET·12V 전원·전기 펌프를 포함한다. 이전 브라우저 급수 초안은 백업한 뒤 새 참조 회로를 불러오며, 이전 초안을 다운로드할 수 있다. 사용자가 이후 삭제한 오브젝트는 자동으로 다시 추가하지 않는다.

- 실행하면 UNO의 D5 → 330Ω → IRLZ44N 게이트를 구동한다. 펌프의 SPICE 전압·전류를 읽어 급수하며, LED는 상태 표시만 담당한다.
- 물통의 물이 줄고, 호스 안의 물방울이 이동하며, 용기의 수위가 올라간다. 토양은 습도에 따라 어두워진다.
- 물의 흡수량을 SEN0193 센서의 ADC 입력으로 되돌린다. 예제 코드가 습도 기준을 만족하면 D5를 끄므로 물도 멈춘다.
- 시간은 브라우저 타이머가 아니라 실행 중인 MCU의 사이클 수로 계산한다. 정지하면 흐름과 물의 양이 멈추며, 카메라·2D/3D 전환으로 초기화하지 않는다.
- 물통이 비었거나 급수 대상·물통·호스가 없으면 물을 이동하지 않는다.

## 사용법

1. 급수 예제의 회로 편집기를 열고 실행한다. 새 예제의 토양 입력은 건조 상태인 560이다. 실제 센서는 건조·젖음 상태를 직접 보정해야 한다.
2. 화분을 선택하면 받은 물과 가상 토양 습도를 확인한다. **토양 말리기**로 급수를 다시 시작할 수 있다.
3. 물통을 선택해 남은 양을 확인하고 **물통 채우기 / 비우기**로 조건을 바꾼다.
4. 펌프의 **자세히 보기**에서 제어 보드·GPIO·센서·MOSFET·별도 전원·급수 대상·유량·용량을 확인한다. 설정 변경은 정지 후 가능하다. 15초 제한으로 정지한 코드는 상단 Reset 후 다시 실행한다.
5. **＋ 주변 오브젝트**에서 화분·빈 용기·물통·펌프·호스를 추가한다. **급수 환경 세트**는 네 오브젝트를 함께 준비한다. 새 회로에 붙일 때는 펌프 설정에서 현재 회로에 급수 연동을 선택하고 실제 배선에 맞는 GPIO를 지정한다.
6. 선택 카드에서 이름·크기·색상을 바꾼다. 화분은 빈 용기 모양으로도 바꿀 수 있다. **이동 활성화**를 켜고 드래그하면 호스의 연결 위치도 따라간다. 선택이 없으면 정보 카드를 표시하지 않는다.

현재 자동 연동은 UNO·SEN0193 입력·IRLZ44N·별도 12V 전원·펌프를 사용하는 급수 시제품 한 세트다. 새 펌프는 전기 부품이며, 회로 배선과 환경 연동을 설정해야 물의 흐름을 표시한다. 빈 용기 모양에서도 센서 입력은 동일한 가상 토양 모형을 사용한다. 이전 프로젝트의 LED 대체 모형은 호환을 위해 유지한다.

## 데이터와 검증 범위

공통 정의는 `data/environment-objects.json`, 전기 부품은 `data/watering-parts.json`이다. 화분·물통·호스는 핀이 없는 `ev-structure`이고 M1 펌프는 두 전기 단자를 가진 `dc-water-pump`이다. 모든 부품은 기존 VLX·초안·서버 저장·실행 취소 수명 주기를 따른다. 물의 양은 실행 중에만 유지하는 상태다.

`EnvironmentRuntime` → `wateringModel` → `environmentStore` → `EnvironmentBody` 순서로 연결한다. 센서 피드백은 기존 `SensorUpdateRegistry`를 통해 ADC와 전기 해석에 전달한다. 사용자 센서 조작도 반영한다.

초기 모형값: 유량 1.5 mL/s, 물통 300 mL(초기 240 mL), 토양 모형 보유량 4 mL, 용기 여유량 20 mL, 흡수율 1 mL/s, 건조/젖음 ADC 560/280. 이 값은 설명용 가정이며 실제 펌프·토양의 특성이나 유체 해석 결과가 아니다. 펌프의 48Ω·5mH와 MOSFET·다이오드 곡선도 근사 모델이다. [실물 참조 설계](watering-reference-design.md)에 확인한 제조사 사실과 미확인 항목을 구분했다.

검증 파일: `tests/test_watering_prototype.py`, `pump-circuit.test.ts`, `environment-objects.test.ts`, `environment-runtime.test.ts`, `watering-model.test.ts`. 실제 ngspice로 펌프 구동 전류·정지·역기전력 클램프를 확인한다. 실제 컴파일한 UNO 펌웨어와 이 해석 결과로 센서 피드백 후 정지를 0.5·1·2배속으로 확인하고, 센서가 계속 건조하면 15초 후 출력이 잠기는지도 검증한다.
