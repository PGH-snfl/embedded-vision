# 빵판 배치와 3D 조립 보기

2026-10-28 업데이트: 현재 기본 3D 화면은 [Circuitiny 편집기](circuitiny-integration.md)이다. 핀 연결·부품 이동·추가·속성 수정·삭제·Undo/Redo를 지원한다. 아래 Three.js 단독 화면은 이전 읽기 전용 구현 기록이다.

초기 구현. 기존 UNO LED 점등·점멸·밝기 조절과 UNO 분압 회로를 대상으로 한다.

## 사용 방법

분석 화면 ③에서 **Velxio 편집기 열기**를 다시 누른다. 새 프로젝트는 **3D 조립**으로 시작한다.

- 드래그로 회전, 휠 또는 ＋/− 버튼으로 확대·축소한다.
- **입체 / 위 / 앞** 시점을 선택할 수 있다.
- 부품을 누르면 `D1 A(양극 +) → 빵판 D11`처럼 꽂을 구멍을 확인한다.
- **2D 빵판** 또는 **2D에서 배선 편집**을 누르면 실제 빵판·부품·선 편집으로 전환한다. 변경한 연결을 3D에서도 사용한다.
- **시뮬레이션 실행**은 기존 AVR 컴파일·AVR8js·ngspice 경로를 사용한다. 3D LED는 계산된 전류/실제 시뮬레이터 상태에 따라 반응한다.

현재 자동 배치는 170구 미니 빵판이다. 같은 열 A~E 다섯 구멍이 연결되고 F~J 다섯 구멍은 별개다. 가운데 홈을 건너 연결하지 않는다. 전원 레일이 없는 모델을 사용하므로 실제 빵판의 레일 분할을 가정하지 않는다.

## 배선

LED: UNO D5 → 빵판 A5, R1 양 끝 → B5/B11, LED A → D11, LED C(K) → D10, UNO GND → A10. R1은 새 설계값 220Ω이다.

분압: UNO 5V → A5, R1 → B5/B11, R2 → D11/D17, UNO A0 → C11, UNO GND → A17. 저항은 각각 새 설계값 10kΩ이다.

부품 다리와 점퍼가 같은 구멍을 차지하지 않도록 배치했다. 다리를 꽂는 연결은 네이티브 `bb: true` 연결로 저장하며 실제 빵판 내부 연결을 통해 전기적으로 이어진다. 단순 배경 그림이 아니다.

`backend/workbench/breadboard.py`는 빵판 내부 연결을 합친 뒤 보드/부품 핀만 남겨 논리 회로와 비교한다. 단락·누락으로 연결이 달라지면 내보내기를 거부한다. 원본 Circuit Graph와 펌웨어 사양은 별도로 검증된다.

## 3D 구현

Three.js 0.186.1(MIT), OrbitControls, WebGL을 사용한다. 회전 가능한 실제 입체 형상으로 보드 두께·커넥터·빵판·구멍·부품 다리·저항·LED·점퍼선을 표시한다. [공식 문서](https://threejs.org/docs/)를 참조했다.

`assemblyModel.ts`는 현재 편집기 store의 부품·배선·삽입 연결을 읽는다. 점퍼의 보드 핀 좌표는 네이티브 2D 캔버스가 측정한 값을 사용한다. 2D 시뮬레이터는 3D 뒤에서도 유지되므로 기존 전기 계산과 MCU 실행이 계속 동작한다. LED 애니메이션을 별도 타이머로 만들어내지 않는다.

3D는 조립 이해용이며 CAD/STEP 모델·치수 공차 검증이 아니다. UNO와 빵판·저항·LED 형상을 우선 지원한다. 미지원 부품/회전 상태, 빠진 삽입 연결, 미해결 좌표를 다른 부품이나 연결로 채우지 않고 표시한다. 초기 화면은 3D 직접 편집이 없었다. 현재는 Circuitiny 기반 화면에서 직접 편집한다.

저장 키에 빵판 배치 버전을 추가했다. 기존에 저장된 평면 배선은 보존하고 새 빵판 프로젝트와 구분한다. 예전 탭의 새로고침만으로 배치가 바뀌지 않을 수 있으므로 분석 화면에서 편집기를 다시 연다.

## 검증

- 프로젝트 Python 테스트 263개 통과: 네트 동등성, 중앙 홈 양쪽의 분리, 구멍 중복 방지, 지원 기능별 실제 AVR 컴파일 및 기존 회귀 테스트.
- 프런트엔드 관련 테스트 92개 통과: 빵판 내부 연결, 실제 삽입, LED 반응, 내보낸 배선→3D 좌표, 좌표 미확인·미지원·삽입 해제 처리.
- Vite 빌드 성공. 프로젝트 전체 TypeScript 검사는 기존 upstream 오류가 남아 통과하지 않는다. 새 assembly 모듈의 검사 오류는 수정했다.
- 실제 브라우저에서 새 빵판 배치, 2D↔3D 전환, 위/입체 시점, 확대, 3D 부품 클릭, 원래 코드의 컴파일과 LED ON/OFF 출력 및 3D LED 켜짐/꺼짐을 확인했다.
- 새로운 사진 분석이나 유료 모델 호출 없이 기존 관측과 검토된 새 설계 규칙으로 검증했다.

자료: `outputs/breadboard-3d/`. 변경 소스 및 재설치용 의존성 버전은 `patches/velxio-embedded.patch`, `patches/velxio-package-lock.json`에 포함한다. 라이브 회로와 실물 동작은 별도 확인 대상이다.
