# 그래픽 시뮬레이터 UI 개선

2026-10-27. 사진 분석 앱에서 여는 `editor?embedded=1` 화면에 적용한다.

- 기본 화면은 밝은 배경의 **회로 보기**. 설계 목표와 예상 동작을 상단에 표시한다.
- **① 회로 확인 → ② 실행하기 → ③ 결과 확인** 순서로 주요 동작을 배치한다.
- **코드 함께 보기**, **보드 출력 보기**, **고급 도구**를 각각 펼칠 수 있다.
- 실행 버튼은 검사·컴파일·실행 상태를 한글로 표시한다. 기존 실행 핸들러, 실제 컴파일, MCU·SPICE 계산을 그대로 사용한다.
- 성공한 컴파일 로그는 자동으로 펼치지 않는다. 오류와 회로 검사 경고는 계속 표시하며 오류 로그를 자동으로 연다.
- 결과 창은 보드 메시지를 먼저 보여주고, 메시지 전송 입력은 추가 토글에 둔다. 오류 로그와 결과 패널을 동시에 강제로 펼쳐 회로를 가리지 않는다.
- 코드·결과 패널 크기가 바뀌면 회로를 다시 맞춰 부품이 화면 밖으로 밀리지 않게 한다. 이는 카메라 이동·확대만 바꾸며 배선·부품 좌표는 바꾸지 않는다.
- 설계 사양·원본과의 차이·자동 저장·최초 제안 복원은 **설계 정보·저장 안내**에 모은다. 실물 미검증 표시는 기본 화면에도 유지한다.
- 파일·부품 추가·파형·개발용 메뉴는 고급 도구에 둔다. 계산 상태 배지는 고급 모드에서 보이고, 계산 경고는 숨기지 않는다.
- 일반 `/editor`는 기존 도구 구성을 유지한다. 변경 소스는 `patches/velxio-embedded.patch`에 포함한다.

## 검증

- Vite 실제 빌드 성공.
- LED 부품, 오래된 컴파일 결과 차단, 컴파일 진행 상태 관련 기존 테스트 72개 통과.
- 실제 브라우저에서 기존 사진의 LED 점멸 회로를 가져와 새 실행 버튼으로 컴파일·실행, 보드 출력 ON/OFF 반복, 정지를 확인했다.
- 코드·결과 펼치기와 회로 자동 맞춤을 확인했다.
- 코드에 임시 문법 오류를 넣어 컴파일 실패·한글 안내·오류 로그 자동 노출을 확인한 뒤 원래 코드로 복구하고 재컴파일했다.
- 오류 시험은 원래 회로를 바꾸지 않으며 테스트용 문법 오류도 제거했다. 새 사진 분석/API 모델 호출은 수행하지 않았다.

증거는 `outputs/simulator-friendly/`에 저장한다. 이 변경은 사용자 인터페이스 개선이며 실물 작동 검증이나 새로운 회로 종류 지원을 뜻하지 않는다.
