# 오브젝트 기본 고정

구조물, 보드, 빵판, 일반 회로 부품은 기본으로 고정한다. 화면에서 선택한
뒤 오른쪽 위의 작은 정보 카드에서 `이동 활성화`를 켜면 그 오브젝트만 드래그할 수 있다.
`이동 완료`, 다른 오브젝트 선택, 선택 해제, 실행 시작, 배선 모드 진입 시
다시 고정한다. 주 편집기에서는 Esc로 진행 중인 드래그를 취소하고 고정한다.
활성화 상태는 프로젝트에 저장하지 않으므로 다시 열면 항상 고정 상태다.

- 주 편집기의 2D/3D 보기는 같은 오브젝트별 이동 상태를 사용한다.
  구조물의 직접 드래그 예외와 보드·빵판의 별도 전체 이동 허용 버튼은 없앴다.
- `objectMovement.ts`의 공통 조건과 실제 이동 명령의 검사로 선택만 하거나
  다른 부품의 이동을 켠 상태에서는 좌표가 바뀌지 않는다.
- 기존 2D 편집기를 열어도 서비스 안에서는 마우스·터치 이동과 빵판에
  놓는 처리를 같은 활성화로 제한한다. 독립 upstream 편집기의 기본 동작은
  유지한다. 이동 후 빵판 접점·배선 갱신과 실행 취소는 기존 처리를 사용한다.
- 운동 미리보기의 구조 편집에도 별도 이동 활성화 버튼을 적용한다. 로봇의
  주행 명령과 가상 운동은 오브젝트 편집 잠금과 별개로 계속 동작한다.
- 내부 보기의 투명 구조물은 목록에서 선택하면 드래그 대상으로 잡을 수 있다.
  구조물 높이 입력과 미리보기의 위치 입력도 이동 활성화가 있어야 변경된다.
- 카드에는 부품명·ID·짧은 정보·고정 상태·이동 버튼을 표시한다. 속성·치수·
  사진 근거·삭제 등은 `자세히 보기`에 접는다. 닫기를 누르면 선택과 이동을 해제한다.
- 배선은 클릭해 선택한 한 가닥만 양 끝 조작점을 표시한다. 다른 부품이나
  배선을 선택하거나 선택을 해제하면 이전 조작점을 숨기고 진행 중인 연결 변경을
  취소한다. 실행·배선 생성 중에는 조작점을 표시하지 않는다.
- 선택이 없으면 편집 화면의 정보 카드·안내 문구·부품 이름표·헤더 연결 설명·
  LED 수치 표시를 숨긴다. 선택한 LED의 밝기와 갱신 주기만 표시한다.
  다른 항목을 선택하거나 빈 공간을 클릭하면 이전 센서·속성 창도 닫힌다.
  Esc는 선택을 해제하고 진행 중인 이동과 배선 연결을 취소한다.
- 실행·부품 추가·화면 전환 같은 공통 도구는 화면 밖 도구 영역에 유지한다.
  조립 가이드와 핀 연결 창은 해당 도구를 직접 켰을 때 표시한다.

재설치: `velxio-loading.patch` → `velxio-object-lock.patch` →
`velxio-selection-card.patch` → `velxio-context-tools.patch` 순서로 적용한다.
